# Tienda Genérica - Sprint 1
Requisitos: Java 11, Maven 3.6+, MySQL 8.
1. Cree/inicie MySQL.
2. En `application.properties` configure usuario y contraseña.
3. Abra como proyecto Maven.
4. Ejecute `TiendaGenericaApplication`.
5. Abra `http://localhost:8080`.
